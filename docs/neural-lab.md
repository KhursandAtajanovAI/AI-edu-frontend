# 3D-лаборатория нейросетей (NN 3D Viz Lab)

Интерактивная лаборатория встроена в платформу как есть: это отдельный статический сайт без сборки,
который лежит в `public/nn-3d-viz-lab/` и открывается внутри приложения на странице `/#/lab`.
Все вычисления выполняются в браузере, сервер и API платформы лаборатории не нужны.

## Источник

- Репозиторий: <https://github.com/KhursandAtajanovAI/nn-3d-viz-lab>
- Опубликованная версия: <https://khursandatajanovai.github.io/nn-3d-viz-lab/>
- Текущая встроенная версия (адрес и коммит): `public/nn-3d-viz-lab/.source.json`
- Лицензия: в репозитории лаборатории файла лицензии нет; права на проект принадлежат его владельцу (владельцу этого форка).
- Three.js 0.169 лаборатория подключает сама через importmap с CDN (`cdn.jsdelivr.net`), поэтому для 3D нужен доступ в интернет.
  Зависимости платформы (`three` в `package.json`) к лаборатории отношения не имеют.

## Как это работает

| Что | Где |
|---|---|
| Файлы лаборатории (каталог, 32 пространства, конструкторы, стили, манифест) | `public/nn-3d-viz-lab/` — Vite копирует папку в `dist/` без изменений |
| Страница в приложении, рамка `iframe` | `src/NeuralLabPage.tsx`, стили `src/neural-lab.css` |
| Маршрут `/lab` (нужен вход) | `src/App.tsx` |
| Пункт меню «3D-лаборатория» у студента и администратора | `src/layouts/MainLayout.tsx`, `src/layouts/AdminLayout.tsx` |
| Переводы пункта и страницы (RU / KZ / EN) | `src/locales/*.json` |
| Адрес папки лаборатории в режиме разработки | `neuralLab.ts` (плагин Vite, подключён в `vite.config.ts`) |
| Адрес папки, кэш и редирект в production | `server.mjs` |
| Обновление лаборатории из GitHub | `tools/sync-neural-lab.mjs` |

Приложение использует `HashRouter`, поэтому адреса вида `/#/lab` не пересекаются с файлами лаборатории
(`/nn-3d-viz-lab/...`). Файлы лаборатории доступны по прямой ссылке и без входа — это статика без данных.
Кнопка «Открыть в новой вкладке» на странице ведёт на `/nn-3d-viz-lab/index.html`.

**Язык и масштаб.** Лаборатория и платформа работают на одном адресе, поэтому страница передаёт настройки
через `localStorage` лаборатории: язык платформы → `nnlab-lang` (русский и казахский → RU, английский → EN),
масштаб `nnlab-scale = 1`, если пользователь ещё не выбирал (по умолчанию у лаборатории ×2). Тема, свои пространства
(IndexedDB), экспорт и импорт работают как в оригинале и хранятся в браузере.

**Что изменено в серверной части.**

- `server.mjs`: файлы `/nn-3d-viz-lab/` отдаются с `Cache-Control: no-cache` (в их именах нет хешей, «вечный» кэш
  не дал бы обновить лабораторию); адрес папки без `/` в конце переадресуется на адрес со `/`.
- `neuralLab.ts`: в `vite dev` адрес `/nn-3d-viz-lab/` отдаёт `index.html` лаборатории (иначе Vite показал бы страницу приложения).
- Backend не менялся: лаборатория его не использует.

## Как обновить лабораторию

```bash
node tools/sync-neural-lab.mjs            # последняя версия ветки по умолчанию
node tools/sync-neural-lab.mjs <адрес> <ветка-или-тег>   # другая версия
```

Скрипт клонирует репозиторий лаборатории, заменяет `public/nn-3d-viz-lab/` и записывает коммит-источник в `.source.json`.
Служебные файлы репозитория лаборатории (`.git`, `.github`, `.gitignore`, `.gitattributes`, `.nojekyll`) не копируются.
Правки вносите в репозиторий лаборатории, а не в копию внутри платформы: при следующей синхронизации копия заменяется целиком.

## Проверка

- `npm test`, `npm run lint`, `npm run build` — в том числе тесты `src/NeuralLabPage.test.tsx`.
- Вручную: войти, открыть «3D-лаборатория», в каталоге открыть пространство (например, «Перцептрон»), создать своё пространство-граф и запустить пример.

## Ограничения и рекомендации

- Внешний Nginx не должен отправлять для этого сайта `X-Frame-Options: DENY` и CSP `frame-ancestors 'none'`:
  иначе рамка не откроется (останется кнопка «Открыть в новой вкладке»). Подойдёт `SAMEORIGIN`.
- CSP, если она включена, должна разрешать скрипты и стили с `cdn.jsdelivr.net` и встроенные скрипты лаборатории (`importmap`).
- Без интернета 3D-сцены не загрузятся (Three.js берётся с CDN). Чтобы работать офлайн, положите Three.js в `public/` и поправьте importmap в страницах лаборатории.
- Пользовательские пространства лаборатории хранятся в браузере и не связаны с аккаунтом платформы.
